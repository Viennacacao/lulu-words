# 文档背词开发计划

## 1. 产品不变量

以下规则在第一版开发中不可被功能扩张破坏：

1. 主页面是只读办公文档模拟器，不是文档编辑器。
2. 学习区只出现在第一页中部，宽度等于正文宽度，高度严格为可配置行数（默认六行，可选八行），并与上下正文各保留 1.2 行间隔。
3. 第一行单词和音标；第二行释义；第三行可编辑助记；第四行短语；第五行英文例句；第六行中文译文。
4. 切换单词、揭示答案和编辑助记不能触发重新分页。
5. 完整学习流程可只用键盘完成，浮动栏只是同一组命令的可视化入口。
6. 第一版所有数据只存本地，不需要账号、服务器或网络。

## 2. 架构边界

应用分为四层：

- `document`：只读文档外观、模板、分页和 DOCX 导入。
- `learning`：学习状态机、快捷键、六行学习区和浮动栏。
- `core`：单词领域模型、复习调度接口，不依赖 React 或 Tauri。
- `infrastructure`：SQLite、文件系统、系统窗口和发音。

依赖方向固定为：界面依赖核心，基础设施实现核心接口；核心不得反向依赖界面。

## 3. 阶段计划

### Phase 0：工程基线

交付：

- React + TypeScript + Vite 工程。
- 严格 TypeScript 配置。
- Vitest 单元测试。
- 架构和验收文档。

退出条件：类型检查、单元测试和生产构建全部通过。

### Phase 1：核心交互原型

交付：

- 模拟办公软件外壳和 A4 第一页。
- 固定六行学习区。
- `recall → revealed → rating → next` 状态机。
- 空格、1/2/3、P、E、方向键、H 快捷键。
- 第三行助记编辑，`Command/Ctrl + Enter` 保存，`Esc` 取消。
- 可拖拽浮动操作栏。

自动测试：

- 回忆状态不能直接评分。
- 揭示答案后评分才能进入下一词。
- 助记保存和取消行为正确。
- 隐藏状态不丢失当前进度。
- 末尾单词可循环到第一词。

人工验收：连续切换 100 次不同长度内容，页面和学习区不发生位移。

### Phase 2：本地数据与复习调度

交付：

- Tauri 2 桌面壳。
- SQLite 数据库和迁移机制。
- 单词、词书、卡片状态、复习日志和助记表。
- `ReviewScheduler` 接口及 FSRS 适配器。
- 应用重启后恢复文档、单词、助记和进度。

自动测试：仓储契约测试、迁移测试、FSRS 评分映射测试、重复提交保护测试。

退出条件：离线完成 200 次复习并重启应用，日志和下次复习时间保持一致。

### Phase 3：只读文档模板

交付：

- 项目周报、会议纪要、财务报告三个内置模板。
- 第一页固定上部、学习区、下部三区布局。
- 第二页及后续普通分页。
- 页面缩放不改变逻辑布局。
- 文档和布局结果缓存。

自动测试：不同窗口尺寸下学习区仍为六行；模板快照和分页边界测试。

### Phase 4：词书与完整本地功能

交付：

- 六套带来源与许可证的离线词书。
- 学习、选词、文本、统计、我的五页顶部导航。
- 公版小说节选、本地 TXT 导入和只读分页。
- 真实字号调整，正文与六行学习区同步重排。
- 今日目标、评分分布和复习日志统计。
- 本地学习偏好和跨词书共享单词进度。

自动测试：词书字段与数量、重复 ID、TXT 规范化、偏好持久化、统计仓储和字号边界。

### Phase 5：DOCX 导入

交付：

- 本地文件选择和 DOCX 大小限制。
- Mammoth 转换、DOMPurify 清理、文档块规范化。
- 段落拆分、表格和图片整体移动。
- 第一页绕开固定学习区分页。
- 导入失败时降级为纯文本排版。

自动测试：普通段落、标题列表、长段落、表格、图片、恶意链接和损坏文件样本。

退出条件：测试样本均不覆盖学习区，不执行导入文档中的脚本或外部资源。

### Phase 6：桌面体验

交付：

- 系统托盘、窗口状态恢复。
- 快速隐藏/恢复学习内容。
- 单实例运行。
- 系统发音和错误日志。
- macOS 安装包。

人工验收：冷启动、快捷键冲突、休眠恢复、多显示器和缩放场景。

### Phase 7：发布前验证

交付：

- 首次使用流程。
- 数据备份和数据库恢复测试。
- 性能、内存和长时间运行测试。
- 发布检查清单和已知限制。

目标：普通文档二次打开无需重新分页；学习操作即时响应；无网络时所有核心功能可用。

## 4. 测试金字塔

- 单元测试：状态机、调度器、分页器和内容规范化。
- 集成测试：SQLite 仓储、DOCX 导入、缓存失效和应用恢复。
- 组件测试：学习区六行结构、按钮状态和快捷键。
- 端到端测试：导入文档到完成一次复习的完整路径。
- 人工视觉测试：A4 比例、文字省略、窗口缩放和浮动栏遮挡。

每一阶段必须同时完成代码、测试和退出条件，不把测试集中拖到项目末尾。
